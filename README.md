# ハローワーク求人を探すワークスペース

このワークスペースは、1人の求職者の希望条件をもとに、ハローワークインターネットサービスの求人を探し、候補と公式の求人票を一時的に保管するためのものです。ここで行うのは求人候補の整理です。応募やハローワークによる職業紹介の手続きは行いません。

## 使い方

初めて取得したときは、`input/` と `求人候補/` フォルダを作り、[未記入の入力テンプレート](templates/job_seeker.md) を `input/job_seeker.md` にコピーしてください。このワークスペースではすでに配置済みです。

このリポジトリは公開用のテンプレートです。実際の入力ファイルが入る `input/` と、検索結果・公式求人票が入る `求人候補/` は `.gitignore` でGitの管理対象から除外しています。これらを強制追加したり、求職者の情報を公開用ファイルに書き込んだりしないでください。求人一覧は検索時にローカルで作成されます。

1. 人が [求職条件入力シート](input/job_seeker.md) の「未記入」を埋める。少なくとも必須の3項目を記入する。
2. 前回の求人情報を残したければ、人が 求人候補/ の必要なファイルを別フォルダへコピーする。AIエージェントに「入力シートをもとに求人を探し、求人票と結果を保存して」と依頼すると、入力条件とサイトの利用可否を確認した後、検索開始直前に 求人候補/ の中身がすべて消去される。検索は依頼ごとに実行し、自動的な定期検索はしない。
3. [求人候補の一覧](求人候補/一覧.md) を開く。各候補のフォルダから、公式サイトで取得した求人票PDFと照合メモを直接見られる。
4. 気になる求人について調べたいことがあれば、求人番号または候補フォルダと質問をAIエージェントに伝える。会社の評判や売上などを公開情報から調べ、事実と推測を分けて結果を残す。未保存の求人も、公式の求人番号またはURLを渡して調査を依頼できる。

## ファイルの配置と担当

| 場所 | 人の使い方 | AIエージェントの扱い |
| --- | --- | --- |
| input/job_seeker.md | 希望条件を閲覧・編集する | 読み取り専用。明示的な依頼がない限り変更しない |
| 求人候補/一覧.md | 最初に確認する今回の結果の入口 | 新規検索前に消去し、作り直す |
| 求人候補/事業所名_職種_求人番号-番号/求人票.pdf | 公式の求人票を開く | ハローワークインターネットサービスからダウンロードして保存する |
| 求人候補/事業所名_職種_求人番号-番号/照合メモ.md | 適合理由、懸念点、確認日時を見る | 求人番号ごとに作成・更新する |
| 求人候補/事業所名_職種_求人番号-番号/追加調査.md | 依頼した調査の結果を見る | 追加調査を依頼された求人にだけ作成・更新する |
| AGENTS.md | 作業手順を確認する | 検索と保存のルールとして守る |

求人候補フォルダはワークスペースの直下に置く、一時的な保存場所です。次の新規検索では、一覧、求人票、照合メモ、追加調査など、中にあるものがすべて消えます。永続的に残したいものは、人が検索前に別フォルダへコピーしてください。AIは自動で退避しません。入力シートは消去対象ではありません。

各求人のフォルダ名は、求人票に表示された事業所名と職種を先頭に、重複を避けるため求人番号を末尾に付けます。事業所名が非公開なら「事業所名非公開」とします。各フォルダには必ず求人票.pdfと照合メモ.mdを置きます。人が日常的に編集するのは入力シートだけです。結果の訂正や条件変更は、入力シートの編集またはチャットで伝えてください。

追加調査だけを依頼したときは求人候補フォルダを消去しません。既存候補の結果は同じフォルダの追加調査.mdに記録し、一覧から開けるようにします。未保存の求人も調べられますが、候補として保管するには公式の求人票PDFを取得して確認する必要があります。評判などの外部情報は公式の求人条件とは分け、出典と調査日を付けます。事業所名が非公開の求人について、外部情報から事業所を推定しません。

## 情報源と保存の範囲

- 情報源は [ハローワークインターネットサービスの求人情報検索](https://www.hellowork.mhlw.go.jp/kensaku/GECA110010.do?action=initDisp&screenId=GECA110010) です。求人票は公式サイトの「求人票を表示」からPDFを取得します。PDFへのリンクだけを置いた状態を「保存済み」とは扱いません。
- 公開検索を使います。求職者マイページへのログイン、求職番号、求人情報提供サービスのAPIは、このテンプレートでは使いません。公開検索では事業所名等が表示されない求人もあります。表示されない情報は推測しません。
- ダウンロードした求人票は原本のままローカルに保管し、外部サイトへ公開しません。照合メモには求人番号、取得日時、公式ページへのリンクと判断理由を残します。
- 求人は変更・取消しがあり得ます。取得したPDFは取得時点の記録として扱い、応募を検討する前に公式サイトで求人番号から最新情報を確認してください。

公式の案内：[求人情報検索のしかた](https://www.hellowork.mhlw.go.jp/member/job_offer_search01.html)、[求人情報の見方](https://www.hellowork.mhlw.go.jp/member/job_offer_search06.html)、[求人票PDFの表示に関するお知らせ](https://www.hellowork.mhlw.go.jp/news/operation_news_dtl.html)、[サイトポリシー](https://www.hellowork.mhlw.go.jp/info/sitepolicy.html)。
